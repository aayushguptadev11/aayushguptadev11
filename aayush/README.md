# Ayush Gupta | Personal Portfolio

A modern, responsive personal portfolio built with **React** and **Tailwind CSS** to showcase my profile, skills, and development journey.

## Tech Stack

- React.js
- Tailwind CSS
- JavaScript
- Vite

## Getting Started

```bash
git clone <repository-url>
cd portfolio
npm install
npm run dev
```
