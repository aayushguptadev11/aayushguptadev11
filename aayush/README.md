## 📖 About The Project

A clean, minimal personal portfolio website designed to showcase Ayush Gupta's profile, skills, and professional social links. The site features a responsive design with a centered profile card, modern styling, and smooth interactions for an optimal viewing experience across all devices — from mobile phones to desktop monitors.

## ✨ Features

- **Profile Card**: Centered circular profile photo with name, title, and bio
- **Responsive Design**: Mobile-first layout that adapts seamlessly to all screen sizes
- **Social Links**: Clickable GitHub and LinkedIn integration
- **Modern Tech Stack**: React 19, Tailwind CSS v4, Vite 8
- **Performance Optimized**: Fast loading, optimized assets, and smooth animations
- **Accessibility**: Semantic HTML and proper heading structure

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository**

```bash
git clone https://github.com/aayushguptadev11/aayushguptadev11.git
cd aayush
```

2. **Install dependencies**

```bash
npm install
# or
yarn install
```

3. **Start the development server**

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the portfolio.

### Available Scripts

| Script | Description |
|--------|-------------|
| `dev` | Start Vite development server with HMR and hot module replacement |
| `build` | Build production bundle with Vite for optimization |
| `preview` | Preview the production build locally |
| `lint` | Run ESLint to check for code quality and style issues |

## 🌍 Deployment

- **Local Preview**: Run `npm run preview` to serve the built portfolio locally
- **GitHub Pages**: The `dist` folder generated by `npm run build` can be deployed to GitHub Pages
- **Netlify**: Drag and drop the `dist` folder or connect the repository for continuous deployment
- **Vercel**: Import the repository and deploy with zero configuration

The `index.html` serves as the entry point with proper meta tags for social sharing and search engine optimization.
